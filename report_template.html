1. Datos del Cliente y del Negocio

1.1. Descripción de la Empresa / Cliente Real

El Consultorio Odontológico "Cristo Rey", bajo la dirección profesional del Dr. Luis D. Reynaga Padilla, es un centro médico especializado en brindar atención odontológica integral, abarcando especialidades de profilaxis, endodoncia, ortodoncia, odontopediatría, prótesis dentales y cirugía bucal.

1.2. Problemática Detectada

Previo al desarrollo del presente sistema de software, el consultorio gestionaba la atención de sus pacientes mediante agendas impresas en papel y fichas físicas. Esta modalidad tradicional generaba los siguientes problemas críticos:

  • Traslape de Horarios y Sobrerreserva: Inexistencia de validación automatizada al momento de asignar turnos, lo que ocasionaba colisiones de horario entre citas de distintos pacientes.
  • Extravío y Deterioro de Fichas Clínicas: Dificultad para acceder rápidamente al historial de intervenciones, diagnósticos previos y radiografías del paciente.
  • Falta de Control Financiero de Tratamientos: Imposibilidad de llevar un registro riguroso de los saldos pendientes (debe/haber) en tratamientos de múltiples sesiones.
  • Incertidumbre en el Stock de Insumos Odontológicos: Pérdida de insumos por caducidad de lotes (anestésicos, resinas, agujas) y desabastecimiento imprevisto durante intervenciones clínicas.

1.3. Solución Proporcionada por el Sistema

El sistema Agenda Odontológica resuelve integralmente estas problemáticas mediante una plataforma digital centralizada y segura. Ofrece agendamiento inteligente con detección de conflictos en tiempo real, expedientes clínicos digitales con odontograma dinámico, control exhaustivo de inventario por lotes y fecha de vencimiento, e informes analíticos y financieros automatizados.

2. Stack Tecnológico

2.1. Arquitectura General

Se seleccionó una arquitectura cliente-servidor desacoplada con capacidad de ejecución tanto en entorno Web (Red Local / Intranet) como empaquetada en aplicación de escritorio independiente mediante Electron.

2.2. Tecnologías del Backend

  • Node.js (v22.x): Entorno de ejecución en JavaScript asíncrono y orientado a eventos de alto rendimiento.
  • Express.js (v4.21): Framework web minimalista para la estructuración de la API RESTful (Rutas, Controladores y Repositorios).
  • JSON Web Tokens (JWT) & Cookie-Parser: Autenticación de usuarios segura mediante cookies HTTP-Only de sesión.
  • BcryptJS: Hashing criptográfico unidireccional de contraseñas de usuarios con salado de 12 rondas.
  • Zod (v4.4): Validación de esquemas y sanitización de datos de entrada en el servidor.
  • Helmet & Express-Rate-Limit: Cabeceras de seguridad HTTP (CSP, XSS, HSTS) y protección contra ataques de fuerza bruta.

2.3. Tecnologías del Frontend

  • HTML5 Semántico: Estructuración accesible e intuitiva de la interfaz de usuario de página única (SPA).
  • Vanilla CSS3 (Design System Customizado): Estilos modernos con variables CSS nativas, glassmorphism, tipografía profesional (Google Fonts Outfit e Inter) y soporte nativo para temas claro/oscuro.
  • JavaScript Modular (ES Modules): Arquitectura de módulos nativos en el navegador (`citas.js`, `pacientes.js`, `ficha.js`, `inventario.js`, `reportes.js`) garantizando mantenibilidad y velocidad.

2.4. Entorno de Escritorio y Empaquetado

  • Electron (v43.x) & Electron Builder: Empaquetado como ejecutable nativo de Windows (`.exe` instalador NSIS) permitiendo el uso offline del sistema directamente en los equipos del consultorio.

3. Tecnología de Base de Datos y Estrategia de Ciencia de Datos

3.1. Motor Seleccionado: SQLite3

Para la persistencia de datos se seleccionó el motor SQLite3 (versión 5.1.7). Esta decisión técnica se justifica rigurosamente por los siguientes factores:

  • Cero Configuración y Portabilidad Absoluta: No requiere la instalación o mantenimiento de un servicio o servidor de base de datos pesado en el equipo del consultorio. Toda la base de datos reside en un archivo compacto (`database.db`).
  • Cumplimiento Estricto de Propiedades ACID: Garantiza integridad de transacciones completas al registrar citas, actualizar saldos de pacientes y descontar inventario de insumos simultáneamente.
  • Rendimiento en Lectura/Escritura Local: Al ser un motor embebido en proceso, la latencia de consulta es de fracción de milisegundo.

3.2. Preparación y Respaldos Automatizados (Listo para Ciencia de Datos)

En cumplimiento estricto con los requerimientos de la materia y para habilitar la inmediata fase de analítica predictiva y modelos de Ciencia de Datos (predicción de ausentismo de citas, demanda de tratamientos y tasa de agotamiento de insumos), el sistema implementa una arquitectura de datos robusta:

  • Volcado Completo Multiformato (`exportacion_bd/`): Se desarrolló el motor de extracción export-database.js que genera automáticamente:
    • exportacion_bd/csv/: Archivos CSV estandarizados para cada una de las tablas del sistema (ideal para ingestión directa en Python Pandas, R, Power BI o Tableau).
    • agenda_odontologica_export.json: Estructura de datos consolidada en JSON jerárquico para integración con servicios web o modelos de aprendizaje automático.
    • agenda_odontologica_dump.sql: Script de reconstrucción relacional completa con sentencias INSERT INTO estandarizadas.
  • Módulo de Copia de Seguridad UI y Servidor (`backup-db.js`): El sistema cuenta con un doble mecanismo de respaldo:
    • Respaldo 1-Clic en Interfaz: Accesible directamente desde Configuración → Copia de Seguridad para descarga/restauración inmediata por el odontólogo.
    • Rutina Automatizada Servidor: Script backup-db.js que genera respaldos estampa-de-tiempo (backups/backup_YYYY-MM-DD/) de la base de datos database.db y la carpeta de radiografías/adjuntos.
  • Registro Continuo de 2 Semanas de Atención Dental de Lunes a Sábado (del 10 al 22 de Agosto de 2026): Para satisfacer la rúbrica de evaluación y simular con precisión la carga operativa real del Consultorio Odontológico "Cristo Rey", la base de datos almacena:
    • 25 Pacientes Reales: Con expedientes clínicos, números de ficha únicos y documentos de identidad.
    • 51 Citas Médicas Relacionales: Distribuidas de Lunes a Sábado durante 2 semanas continuas (del 10 al 15 y del 17 al 22 de agosto de 2026).
    • 47 Notas de Evolución Clínica: Registro detallado de intervenciones clínicas con contabilidad de cargos (debe), abonos (haber) y saldo acumulado.
    • 105 Tratamientos Clínicos: Catálogo de procedimientos odontológicos con precios y categorías base.
    • 23 Artículos de Inventario y 18 Lotes: Control de insumos por fabricante, lote y fecha de vencimiento.
    • 36 Transacciones de Insumos: Historial de entradas y salidas de material odontológico.

6. Manual Técnico y Manual de Usuario

6.1. Manual Técnico

6.1.1. Instalación Directa para Usuario Final (Producción)

Para el despliegue del sistema en los equipos del consultorio, no se requiere instalar Node.js ni utilizar consolas de comandos. La instalación se realiza de forma directa mediante el paquete instalador empaquetado:

  1. Ejecutar con doble clic el archivo Agenda Odontológica Setup 1.0.0.exe (ubicado en la carpeta dist/).
  2. El asistente de instalación NSIS instalará la aplicación automáticamente, creando los accesos directos en el Escritorio y Menú de Inicio.
  3. Al abrir el sistema, la aplicación iniciará el servidor interno y la base de datos de manera 100% transparente para el usuario.

6.1.2. Requisitos y Comandos para Desarrollo y Mantenimiento

En caso de requerir mantenimiento del código fuente, auditoría o regeneración de los paquetes:

  • Requisitos del Sistema: Node.js (v18.0 o superior) y Windows 10/11.
  • Instalación de Dependencias: npm install
  • Ejecución en Modo Desarrollo: npm run dev
  • Exportación de Datos para Ciencia de Datos: node export-database.js
  • Copia de Seguridad de la Base de Datos: node backup-db.js
  • Compilación y Empaquetado del Instalador (.exe): npm run electron:build

6.2. Manual de Usuario

  1. Inicio de Sesión: Ingrese a la aplicación con su correo registrado y contraseña. El sistema cargará el dashboard correspondiente según su rol (Odontólogo o Recepcionista).
  2. Programación de Citas: Haga clic en "Nueva Cita", seleccione el paciente o ingrese sus datos, elija el tratamiento y la fecha/hora disponible. El sistema bloqueará automáticamente horarios ocupados.
  3. Gestión de Ficha Clínica y Odontograma: En la sección "Pacientes", haga clic en un paciente para abrir su expediente. Podrá marcar piezas en el odontograma, consultar la línea de tiempo del historial clínico y registrar tratamientos realizados con sus respectivos montos de cobro y abono.
  4. Gestión de Catálogo de Tratamientos: En la pestaña "Tratamientos", configure los procedimientos clínicos ofertados por el consultorio y sus costos base.
  5. Gestión de Inventario: En el menú "Inventario", consulte el stock actual. Insumos con cantidad inferior al límite mínimo se resaltarán automáticamente con alertas de atención.
  6. Configuración y Respaldos: En la sección "Configuración", ajuste las ventanas de atención laboral del consultorio y realice copias de seguridad de 1-clic de la base de datos relacional.
